# 机器狗导航与实时避障验收指标框架

- 日期：2026-11-24
- 状态：指标定义与测量方法已建立；最终阈值待本体速度/制动能力、部署场地与任务等级确定
- 唯一进度台账：[TaskPlan.md](../../TaskPlan.md)

## 1. 指标制定原则

1. 仿真、公开 rosbag、台架、HIL、封闭区域和户外测试分开记录，不跨层级替代。
2. 所有延迟指标同时记录 P50/P95/P99 与最大观测值；不只报告平均值。
3. 所有精度指标必须有独立真值设备/标定板/测量基准，不能用同一算法自身输出作真值。
4. 每个障碍物测试保留原始传感器 bag、标定版本、软件 commit、环境光照/天气、距离和速度。
5. 最终门限必须与机器狗厂商允许的速度、加速度、步态、载荷和制动距离一致；未拿到这些数据前不猜测通过阈值。

## 2. 安全停车距离与响应时间

### 2.1 端到端响应时间分解

测量从障碍物进入传感器有效视野到机器人实际开始减速/停止的各段耗时：

| 子项 | 测量点 |
|---|---|
| Sensor age | 采集时间至 ROS 消息被感知节点接收 |
| Perception latency | 点云/图像采集至有效障碍物输出 |
| Costmap latency | 障碍物输出至 local costmap 更新 |
| Controller latency | costmap 更新至新速度命令产生 |
| Safety latency | Collision Monitor 检测至零速/减速命令输出 |
| Transport/actuator delay | 命令离开 AGX 至底层实际开始减速 |
| Physical stop time | 实际开始减速至机体完全静止 |

分别报告总响应时间 P50/P95/P99、最大值和停止距离分布；记录低电量、负载、步态切换、斜坡和地面材质对结果的影响。

### 2.2 停车距离约束

用于初步设计的物理下界参考：

D_required = v_max × T_total + v_max² / (2 × a_brake_min) + M

其中：
- v_max：该测试场景批准的最高行走速度；
- T_total：测得的感知到制动响应时间；
- a_brake_min：该载荷/步态/地面条件下实测的最小有效减速度；
- M：由测量不确定性、机体姿态变化、障碍物运动和安全风险分析确定的额外余量。

此公式是假设近似恒定减速度的工程估算，不是四足机器人的制动保证。实际验收必须测量从障碍物首次可见到机体完全停止的距离，使用观测到的 P95/P99 及场景余量确定保护区，不得只用理论值。

## 3. 定位与时间同步

| 指标 | 计算/测量方式 | 最终阈值 |
|---|---|---|
| Local odometry APE | 对齐独立地面真值，计算轨迹绝对位置误差 RMSE/P95 | 待确定 |
| Relative Pose Error | 固定时间间隔与固定行进距离两种窗口计算 RPE | 待确定 |
| Heading error | 与独立航向真值比较，静止/直行/转弯分别记录 | 待确定 |
| Drift | 每 100m、每 10min 和每次步态切换记录漂移 | 待确定 |
| Odom frequency/age | 消息实际频率、P95/P99 age、最大 stale 时长 | 待确定 |
| LiDAR-IMU offset | PTP/硬件时间戳与采集时间对齐，测量 offset、drift 和恢复 | 待确定 |
| Stereo exposure skew | 示波器/硬件触发和高速运动靶标双重验证 | 待确定 |
| GNSS correction age | 记录 RTCM 改正龄期、FIX/FLOAT/Single 状态与恢复时间 | 待确定 |

定位失效、TF 断链、时间戳倒退、协方差异常或数据过期时，应验证导航层进入降速/停止，而不是沿用旧定位继续运动。

## 4. 障碍物感知指标

必须按类别和距离分层，至少包含：墙面/箱体、行人、细杆/电线、低矮障碍、玻璃/透明材质、反光材质、无纹理物体和负障碍/沟槽。

| 指标 | 测量方式 | 最终阈值 |
|---|---|---|
| Detection precision/recall | 以人工标注/测量真值统计 TP/FP/FN | 待确定 |
| First detection distance | 沿机器人运动轨迹测首次稳定输出障碍的距离 | 按类别确定 |
| Range error | 与标定测距设备对比，报告 RMSE/P95 | 按距离段确定 |
| Height/width coverage | 对矮物、悬空物、窄物测有效检测高度/宽度 | 按外形和安装高度确定 |
| False obstacle rate | 空场/地面纹理/动态阴影场景单位时间误报次数 | 待确定 |
| Missed obstacle rate | 进入预定测试走廊而未被标记的障碍占比 | 待确定 |
| Output latency | 采集时间至有效 PointCloud2/track 输出 | P95/P99 待确定 |
| Data validity | 无效视差率、点云丢帧、topic age、TF lookup 失败次数 | 待确定 |

LiDAR 与 stereo 独立统计后，再统计融合效果。Stereo 无效视差不能直接解释为空闲空间；清除 costmap 必须使用经过验证的 free-space 证据。

## 5. Nav2 路径与控制性能

- 路径跟踪横向误差：以独立定位真值和规划路径比较，记录 RMSE/P95/最大值。
- 目标到达误差：记录位置和朝向误差、成功率、超时率。
- 路径效率：实际轨迹长度 / 全局规划长度。
- 恢复行为：规划失败、局部堵塞、传感器退化时恢复次数、耗时和最终成功率。
- 动态行人：迎面、横穿、同向、突然进入、离开后重规划；记录最小人机距离和停止/绕行行为。
- 窄通道：按机器人实际宽度和安全间隙逐级减小；记录碰撞、刮碰、停滞和误停。
- 命令链独占：确认只有一个安全出口可以驱动 Lite3；任意其他速度发布者必须被拒绝/诊断。

最终阈值需在获取 Lite3 允许的线速度、角速度、横移能力、加速度和命令 timeout 后确定。

## 6. RTK 与 GNSS 降级

在开放天空、树荫、建筑遮挡、多路径、移动遮挡、RTCM 中断和恢复条件下测量：
- FIX/FLOAT/Single 状态占比；
- 水平/垂直误差与 covariance；
- correction age、卫星数、DOP；
- RTK 首次 FIX 时间、丢失时间、重新 FIX 时间；
- GNSS 被 quality gate 剔除时 local odometry 漂移；
- GNSS 恢复后 map→odom 的修正幅度、连续性与重规划次数。

单天线 RTK 静止不提供机身 yaw 真值；必须使用经验证的 local heading 或后续独立航向源。

## 7. 地形与四足可通行性

阶段 F 另行统计坡度、台阶高度、路沿、沟槽、负障碍、松散地面、草地、砾石、湿滑和混合材质：
- traversability 分类 precision/recall；
- 地面高程误差、坡度误差、粗糙度估计误差；
- 足端滑移次数/距离和机体姿态超限事件；
- 跌倒、触地、越障失败、人工接管次数；
- 通过率与通过时间。

Nav2 2D obstacle avoidance 的成功不能替代底层落足安全验收。未获得厂商允许的地形能力和步态限制前，不把标称越障高度/坡度当作自主通行阈值。

## 8. 电源、热与长时间运行

- 全部外设同时运行时测量电压、电流、瞬态、功率和转换效率；
- 记录 Jetson CPU/GPU、内存、温度、降频和节点重启；
- MID-360、双相机、RTK、交换机同时运行时记录丢包和 USB reset；
- 记录上装整机质量、重心、机身俯仰/横滚惯量影响；
- 在厂商批准的载荷和场地条件下测量任务续航与电池余量；
- 连续运行时记录 ROS topic age、TF freshness、rosbag 文件完整性与磁盘剩余空间。

## 9. 场景矩阵与证据要求

每个正式场景至少记录：
1. 机器狗 SKU、固件、载荷质量、重心和电池状态；
2. 软件 commit、ROS distro、驱动/模型/参数版本；
3. 传感器安装尺寸、外参、标定文件和时间同步状态；
4. 环境/地面/光照/天气、障碍物类型与真值尺寸；
5. 测试速度、步态、轨迹、重复次数和人工接管；
6. rosbag、真值轨迹、日志、计算指标脚本和结论；
7. 失败原因、复现步骤、修复 commit 和回归结果。

**当前结论：** 指标定义和测量方法已完成初稿；由于实际 Lite3 运动能力、制动、场地风险等级和应用速度仍未获得确认，所有硬性数值阈值保持待定。该文档不能作为采购或实机安全放行文件。
