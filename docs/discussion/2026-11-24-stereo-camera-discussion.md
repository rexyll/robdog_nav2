# 前序讨论归档：两台普通 2D 相机能否替代 RGB-D 深度相机

- 日期：2026-11-24
- 目的：保留前一轮技术讨论结论，作为本项目传感器选型和双目感知边界依据。

## 1. 讨论问题

在机器人应用场景中，两个普通 2D 相机在哪些场景下可以替代 3D-RGB 深度相机识别障碍物，哪些场景下不能替代？

## 2. 核心结论

两台普通 RGB 相机在固定安装、足够视场重叠、完成内外参标定并且同步采集的情况下，可以构成被动双目视觉系统，通过左右图像视差计算深度，并生成深度图/点云。因此，在纹理与光照合适的环境里，可承担大量导航障碍物检测工作。

但“两台普通相机”不是天然的 RGB-D 设备。需要额外实现硬件刚性安装、相机标定、双目校正、时间同步、视差计算、深度置信度过滤和点云坐标转换。

## 3. 较适合的应用

- 室内移动机器人导航和较大障碍物识别；
- 仓储 AMR 对货架、托盘、箱子、墙壁的识别；
- 行人识别与距离估计；
- 室外被动视觉测距（在光照、纹理和运动条件合适时）；
- 巡检和环境三维重建；
- 机械臂工作区的粗粒度空间监测（需验证精度）。

## 4. 不应依赖普通双目作为唯一传感器的情况

- 透明玻璃、透明塑料、镜面和高反光材质；
- 无纹理、低纹理和重复纹理区域；
- 黑暗、强逆光、严重运动模糊；
- 左右相机未同步、机器剧烈振动；
- 细电线、薄杆、小目标、近距离遮挡边界；
- 需要高精度近距离接触操作或安全级防护。

主动深度相机也不是万能：ToF、结构光、主动双目各有材质、阳光、距离和多径限制。

## 5. 原理与误差

理想双目测距：

[
Z = \frac{fB}{d}
]

深度误差近似：

[
\sigma_Z \approx \frac{Z^2}{fB}\sigma_d
]

距离增加后深度误差会明显放大。更大基线和更高有效分辨率可改善远距离深度估计，但更大基线会增加近距离遮挡并降低视场重叠。

## 6. 对本机器狗项目的设计影响

- 两台普通 RGB 相机定义为**被动双目视觉**，不将其误称为原生 RGB-D；
- LiDAR 仍是主几何避障传感器；
- Stereo 输出独立 PointCloud2，作为补充几何观察源进入 Nav2 local costmap；
- RGB 目标检测负责类别和跟踪，不把类别识别等同于准确三维距离；
- 对玻璃、反光、无纹理和细小障碍物建立专项测试；
- 复杂近距离避障和安全相关区域必须使用多源冗余和独立停止链路。

## 7. 本轮新增的项目问题

用户提出将 LiDAR、RTK、两台普通 RGB 2D 相机部署在四足机器狗上，通过 ROS 2 Nav2 完成整套导航与实时避障。本仓库据此采用：
- IMU + 腿式里程计 local EKF；
- RTK + navsat_transform + global EKF；
- LiDAR + Stereo 独立观测源；
- Global/Local Costmap、Planner、Controller、BT；
- Collision Monitor、cmd_vel adapter 与四足控制器；
- 地形可通行性作为 Nav2 2D costmap 之外的后续增强阶段。
